# ЖилКомСервис — Управляющая компания

Веб-сайт управляющей компании «ЖилКомСервис» — информационный портал для жильцов и администрации. Проект разработан в рамках учебной практики.

Сайт автоматизирует взаимодействие между жителями и управляющей компанией: позволяет просматривать информацию о домах, тарифах, подавать заявки на ремонт и отслеживать их статус.

## Функционал

- **Главная страница** — карусель услуг, список домов под управлением, сводка по тарифам и финансированию, новости и объявления, контактная информация
- **Дома** — каталог многоквартирных домов с фильтрацией (поиск по адресу, состояние, наличие лифта), сортировкой и пагинацией; детальная карточка дома с информацией о фонде ремонта и связанных заявках
- **Тарифы** — таблица действующих тарифов на жилищно-коммунальные услуги; отчётность по расходованию средств с детализацией по годам
- **Подача заявки** — форма для отправки заявки на текущий или капитальный ремонт с привязкой к дому и квартире
- **Статус заявок** — просмотр всех поданных заявок с фильтрацией по статусу (запланирована / в работе / выполнена)
- **Личный кабинет** — профиль жителя с историей его заявок
- **Администрирование** — панель управления для сотрудников УК: сводная статистика, управление домами (добавление, редактирование, удаление), управление заявками (назначение в работу, завершение, удаление)

## Технологии

- **HTML5** — семантическая вёрстка
- **CSS3** — адаптивный дизайн, flexbox/grid, кастомные стили
- **JavaScript (vanilla)** — вся логика клиентской части без сторонних библиотек
- **localStorage / sessionStorage** — хранение данных и сессий пользователей на стороне браузера
- **GitHub Pages** — хостинг статического сайта

## Локальный запуск

Просто откройте `index.html` в любом современном браузере. Серверная часть не требуется.

## Хостинг на GitHub Pages

Сайт загружен в GitHub-репозиторий и доступен по адресу:

**https://isohisokeee.github.io/zhilkomservis/**

При пуше изменений в ветку `main` сайт обновляется автоматически.

## Особенности реализации

- Данные предзаполнены демо-информацией: 8 домов, 9 заявок, тарифы и статьи расходов
- Карусель услуг на главной работает с автоматической прокруткой
- Модальное окно дома показывает детальную информацию и связанные заявки
- Администратор может менять статус заявки (запланирована → в работе → выполнена) с указанием стоимости работ
- При выполнении заявки стоимость списывается из фонда дома
- Адаптивная вёрстка для мобильных устройств

## Примечание

Все данные хранятся в localStorage браузера. Синхронизация между устройствами не поддерживается — учётные записи, заявки и изменения не передаются между разными компьютерами. Для полноценной многопользовательской работы требуется внедрение серверной части (бэкенда) и базы данных.
